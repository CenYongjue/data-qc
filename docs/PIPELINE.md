# 算子、顺序与边界

## 1. 输入与规范化

视频入口 `video_quality_pipeline_v2.py` 自动识别 LeRobot v3 的 info/episodes 元数据或 EgoDex MP4/HDF5，也支持 `--manifest` 明确多路归组、时间基准和角色。LeRobot 拼接 MP4 按元数据中的回合起止秒读取，复核片段不得跨回合。

SynData 先用专用转换器，AgiBot v2.1 用官方迁移工具；这些不是任意目录通用转换器。转换参数和输入布局见对应 README。转换、视频检查、机器人运动检查、动作一致性目前各自独立执行和保存报告。

## 2. 视频文件与时间轴

- 文件存在、非空、可打开；捕获解码异常与损坏标记。
- HDF5 或 Parquet 可读、必要字段、数组维度、长度、索引及时间戳等适配检查。
- LeRobot 显式 `valid.frame=false` 标记为源无效帧问题。
- 完整解码检查帧数、PTS 单调性、时间跳变、回合覆盖；多路检查共同时间轴覆盖。

能够发现可见的文件/导出时间轴异常，不能证明原始硬件严格同步，也不能保证识别已被补帧掩盖的采集丢帧。

## 3. 画面检查

| 项目 | 方法 | 当前要点 |
|---|---|---|
| 过暗/过曝 | FFmpeg signalstats + 暗亮像素比例 + 分区均值/覆盖 | 4Hz，持续2秒，多个条件结合；低纹理本身不等于曝光异常 |
| 模糊/低纹理 | Sobel 定位边缘，仅边缘上计算绝对 Laplacian 响应 | 4Hz；边缘不足时清晰度不可评分，不能把低分直接等同模糊 |
| 冻结/重复帧 | FFmpeg freezedetect + 恢复时帧跳变 | 正常静止保留提示；显著恢复跳变才提升候选严重度，不能彻底区分所有重复帧与静止 |
| 闪烁/闪光 | 全帧亮度变化、短时往返、场景变化排除 | 不只使用4Hz画质样本 |
| 镜头抖动 | 网格特征点、LK 前后向、RANSAC 全局运动、边缘加权、轨迹残差与往返 | HiFi-UMI仅头部两路；集中中心/覆盖不足降低可信度，不把操作者运动直接当镜头运动 |
| 压缩块 | FFmpeg blockdetect，各区域分数，面积与持续性条件 | fast关闭；开启要求至少50%区域持续1秒等，开销较大 |
| 色度花屏候选 | 色度突变及恢复 + 块分数佐证 | 关闭块检测时此确认分支跳过，不声称覆盖所有花屏 |

分区并非每项都单独跑16个滤镜：曝光分区通过像素统计；块检测才有代价较高的区域滤镜。实际阈值以配置为准，不要混用旧脚本参数。

## 4. 最后做人手可见性

人类 EgoDex 用手部专用 YOLO、GPU 批量推理、CPU 解码与 GPU 流水并行。连续3秒没有检测到任何手为候选；单手可见不触发“双手不可见”。采样4Hz。

机器人跳过手/夹爪可见性。不能通过通用 COCO 模型判断手；检测失败也可能来自遮挡、视角或模型漏检，并非直接证明手不在画面。

## 5. 机器人运动（旧 AgiBot 独立入口）

- 每维统计范围 `[p1-k*(p99-p1), p99+k*(p99-p1)]`，k可调，不是硬件物理限位。
- 平滑残差及其导数，与滤波高频分量两套抖动判据；任一触发为候选。滤波仅评分，不替换原轨迹。
- 仅裁剪首尾静止段，不裁剪操作中间暂停；保留对比片段。
- `agibot_clean_v1.py` 依赖旧 AgiBot 字段映射，不能直接用于58维新 action 文件。默认只抽10条，PASS 子集另存。

## 6. 动作—状态一致性（新入口）

按关节名称映射绝对位置目标/状态、弧度制，检查有限值和时间。根据目标变化速度与实际速度互相关确定非负候选延迟，负延迟用于诊断。按后续指令覆盖边界建立评价窗口，按 W 归一化后计算方向、进度和响应幅度。

窗口与 Episode 都有可评价性：部分执行不直接异常，未到位不直接异常；无响应/反向仅是待查。默认不以行为比例直接判 FAIL。不能仅凭曲线验证 State 实测来源或真实指令发布时间。已知限制：整回合共用延迟、宽峰置信度规则较严、阈值未做正常样本校准。见动作 README。

## 7. 输出与复核

PASS：当前阈值下未触发候选，不保证无漏检。REVIEW：需要人工复核。FAIL：明确基础错误，或对应旧模块定义的严重错误。UNASSESSABLE：新动作模块无法可靠评价，不应剔除。视频内部 WARN、SKIPPED、UNSCORABLE 应区别于已检查通过。

视频输出分类网页、每回合原因与指标、问题片段/速览、进度与运行统计。动作输出每窗口 Parquet、Episode CSV、互相关曲线与诊断图网页。默认不为每条正常回合生成整段标注视频，以减少编码开销。
