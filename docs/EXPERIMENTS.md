# 实验状态与后续工作

## GPU解码实验（非推荐默认入口）

- `hifi_umi_qc_gpu_decode.py`：每回合新建 PyAV CUDA 解码器，初始化与传输开销使本次实测慢于CPU。
- `hifi_umi_qc_persistent_gpu.py`：四卡各自连续四分之一回合，复用6路解码器，通过共享内存交CPU。分四段只是现有实现选择，不是四GPU必须这样分配。实测仍慢于CPU无块方案。
- `hifi_umi_qc_gpu_pixels.py` / `video_qc_v2/gpu_quality.py`：PyNvVideoCodec + DLPack + Torch，GPU缩放/灰度/曝光/边缘/帧差，CPU头部LK。解码器缓冲区复用必须先clone再积攒批次。

GPU像素四卡版本曾超时中止；233条部分结果与CPU对照223条类别相同、10条存在差异，未完成定位。PyNv接口还缺少CPU解码路径的逐帧is_corrupt标志，不能声称损坏检测等价。目前只保存代码供研究，不应替代正式默认流程。需CUDA/驱动、NVDEC与PyAV硬件支持；A100不支持AV1硬解，不安排先CPU转码再硬解。
