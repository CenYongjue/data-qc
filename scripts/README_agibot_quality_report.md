# AgiBot 第一轮质量报告（只读）

```bash
cd /data_all/cenyj
source conda.sh
conda activate intern_pipeline
python -u scripts/agibot_quality_report.py \
  --dataset lerobotv3_output/agibot \
  --output lerobotv3_output/agibot_qc_round1 \
  --config scripts/agibot_qc_config.json
```

只生成报告、裁剪建议和复查视频，不实际删除、裁剪、修复、重对齐或平滑原数据。针对当前 AgiBot 字段，不是任意数据集的通用适配器。输出已存在时拒绝覆盖，改阈值后使用新目录。

## 复查入口

- `index.html`：每条轨迹的原因及视频。
- `episodes.csv`：状态、原因、建议操作和建议保留帧范围。
- `episodes/episode_*.json`：指标、异常区间、各相机状态和证据路径。
- `video_samples.csv`：逐相机抽样点的亮度、暗/亮像素比例、边缘覆盖率和模糊指标。
- `overviews/*.mp4`：默认每秒抽一帧、额外包含末帧，以 5 fps 播放的三视角速览。不是原速视频，不能用于判断速度/高频抖动；画面时间是源 episode 时间。
- `evidence/*.mp4`：FAIL/REVIEW 轨迹至多 2 个问题片段，每段约 6 秒、30 fps 原速、三视角并排；只有裁剪建议时展示边界片段。其余异常时间见 JSON。
- `manual_review.csv`：人工填写保留/剔除/裁剪决定、原因是否正确、批准的裁剪范围及备注；不会自动执行决定。
- `calibration.json` / `config.json`：本轮统计阈值及配置。
- `performance.md` / `performance.json`：实际耗时、每小时可处理的轨迹/相机视频时长、运行硬件和测量范围。三相机共用时间轴，轨迹时长不重复乘三。

FAIL：规则不合格、作为整条剔除候选，未实际剔除。REVIEW：统计异常、冻结、近重复或清晰度不确定，待人工复核。PASS：通过本轮已实现规则，可以附带 WARN；不代表所有质量问题均已排除。

三路相机分别判定；任一路 FAIL/REVIEW 会传递到轨迹。未做的检查明确列为限制，不伪装为已通过。

## 指标和阈值的含义

1. 数值/时间：检查 NaN/Inf、连续帧号、递增时间和 timestamp=frame_index/fps。前提是 v3 元数据和 Parquet 可读；不可读的整个分片使运行失败，不伪造逐帧结论。视频只检查抽样读取，未完整解码。
2. 关节统计范围：状态和动作分别逐关节计算 P1/P99，外扩范围的 10%。异常比例至少 1% 或连续至少 0.3 秒记 REVIEW。这不是机械限位，当前 32 条轨迹不是整个 AgiBot 分布。
3. 抖动候选：末端位置按各维 P99-P1 缩放，7 帧居中移动平均作为参考。残差及其一/二阶时间导数范数与 median+8*1.4826*MAD 比较，三者同时超限至少 0.1 秒记 REVIEW。排除平滑边界，不覆盖数据，不直接平滑四元数。
4. robot.orientation 零范数记 WARN，不单独剔除演示，不补成单位四元数。
5. 图像指标统一在 320x240 计算：均值<45 且亮度<30 的像素超过 65% 为偏暗；均值>210 且亮度>245 的像素超过 50% 为过曝。Sobel 幅度>20 的边缘至少占 1% 时，计算边缘上的平均绝对 Laplacian 响应，<8 为模糊候选。以上问题至少占 30% 有效抽样点且至少 3 点记 FAIL。边缘不足占 50% 且至少 3 点记 REVIEW，不把低纹理判作模糊。全部图像阈值是待人工校准的初值，不加权合分。
6. 冻结候选：原尺寸解码帧在连续抽样点完全相同至少 3 秒，同期关节变化超过统计范围 5%，记 REVIEW。不能据此证明丢帧，也不能排除短暂冻结或画外运动导致的假阳性。
7. 去重：完整数值序列与全部抽样图像摘要一致时，后出现轨迹标为重复候选。近重复将状态/动作关节序列按进度重采样到 64 点，范围归一化后的 RMS 距离<0.03 记 REVIEW，未证明视觉场景相同，不自动删除。
8. 首尾裁剪：联合实测关节、末端位置、夹爪的变化，阈值为每秒相对范围变化>0.02。前后各留 0.5 秒，至少裁去 0.5 秒，至少保留 2 秒；保护 action_config 标注。结束边界未确认，保守多保留一帧。中间静止不删，整段无运动不裁空。输出范围为 [start_frame,end_frame_exclusive)。

未执行：执行器遮挡检测、学习式 IQA、真实传感器时钟恢复、控制延迟修正、物理限位检查、任务成功判断、修复。没有模型/说明时不伪造结论。

依赖 intern_pipeline 中已有 numpy、pandas、pyarrow、opencv、av 和 ffmpeg，无需 GPU。按视频分片偏移寻址，缓存容器，避免重复全量解码；仅对选中的问题区间生成原速片段。

脚本现在使用 perf_counter 对准备、指标分析及速览、去重、原速证据生成和报告写出分阶段计时。用户在首轮运行结束附近提出测速要求，因此本次首轮时间由输出文件时间戳近似重建；修正裁剪证据位置的额外运行单独计时，报告明确区分两者。不要把本轮 1 Hz 抽样吞吐当成全帧视频检测或含学习模型的速度。
